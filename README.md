# Просебя · лендинг · верстка · версия 2

Чистая статическая верстка (HTML + CSS, без сборки) по макетам в Paper
([файл](https://app.paper.design/file/01M4G9XECW85DD0WF65E9257BT), страница «Лендинг · Шапка, Hero, Для сотрудника»).
Основа — живой сайт [prosebya.ru](https://prosebya.ru/), баннер «Остаёмся на связи» — из макета Figma.

**Что отличает версию 2 от первой** ([prosebya-landing](https://github.com/leratk22/prosebya-landing)):
на десктопе синяя плашка по ширине вёрстки (вровень с логотипом и кнопкой шапки), опущена между шапкой и hero, кнопки в ней нет,
«временный сервис» оформлен ссылкой. На мобильной плашка на всю ширину, текст единой фразой, справа круглая кнопка-стрелка.

В верстку вошло:

1. Шапка: логотип, меню, кнопка «Оставить заявку» (на мобильной — бургер с выпадающим меню).
2. Баннер «Остаёмся на связи» между шапкой и контентом: «временный сервис» — ссылка на `sessions.prosebya.ru`.
3. Hero «Развиваем внутреннюю силу команды».
4. Блок «Для сотрудника».

## Запуск

```bash
python3 -m http.server 4318
```

Открыть: http://localhost:4318/

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | Разметка страницы |
| `css/styles.css` | Токены (имена как в Paper), стили, мобильная версия |
| `fonts/` | Euclid Circular A: Regular, Medium, SemiBold |
| `assets/logo.svg` | Логотип Просебя |

## Адаптивность

Дизайн: десктоп 1440, мобильная 375, брейкпоинт `960px`. От 960 до 1440 заголовки и коллажи масштабируются
вместе с шириной окна. Шире 1440 вся страница растёт пропорционально ширине окна, как на prosebya.ru
(`zoom = ширина окна / 1440`, скрипт в `<head>`). Картинки коллажей позиционируются в процентах от коробки коллажа
(`--l / --t / --w` — десктоп, `--ml / --mt / --mw` — мобильная), поэтому сохраняют композицию макета.

## Допущения

- Картинки коллажей и логотип «Ренессанс» подключены с CDN сайта (`static.tildacdn.com`), локально они не хранятся.
- Ссылки меню и кнопок ведут на prosebya.ru; кнопка «Протестировать свою команду» — на якорь `#team-testing`, как на сайте.
- Бургер-меню на мобильной — единственный JS на странице (несколько строк в конце `index.html`).
